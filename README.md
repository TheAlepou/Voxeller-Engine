# Voxeller Engine

## What is it?

It is a voxel "engine" I made for fun written in Rust, Metal and Vulkan.

It is currently available only on macOS

![Image Alt](https://github.com/TheAlepou/Voxeller-Engine/blob/main/screenshots/v0.0.1-alpha_test.png)

## How do I build it?

1. Install Command Line Tools for Xcode
2. Install Rust-lang
3. Run it like any other Rust program via the cargo run command.

## How do I use it?

Check the releases page and download it from there.

### Engine Controls:

Left-click to capture mouse / enter FPS mode

Mouse	Look around

W / S	Fly forward / backward

A / D	Left / right

Space / E	Move up

Shift / Q	Move down

Escape	Release cursor

Press F then P then S for the FPS counter and developer data
